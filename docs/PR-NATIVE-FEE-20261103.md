# PR：跨链原生币手续费（阶梯，转给收款地址）

> 状态：**代码与测试完成，未部署，不授权任何链上动作。** 分支 `native-fee-20261103`。

## 1. 目标

平台目前承担目的链放行 gas，用户只付源链 gas。要把用户的跨链成本抬高到平台成本的 5–10 倍：用户存入时额外付一笔 BNB（BSC 方向）或 WANT（WANTOS 方向），**按存入金额分 4 档收固定值**，收到后立刻转给收款地址（负责人离线钱包 `0xADCDe89431978C79ef66956Cfed67ac925426957`）。不动 USDT 本金，不改对账口径。

## 2. 设计

| 项 | 内容 |
|---|---|
| 入口 | `BscVaultV2.deposit`、`WantosBridgeV2.bridgeOut` 变 `payable`，`msg.value` 必须恰好等于该档费用，否则整笔回滚 |
| 档位 | `limits[3]` 升序（按实际到账额 `received` 计档）、`fees[4]`；`quoteNativeFee(amount)` 供前端报价 |
| 转账 | 在状态写入之后、事件之后转给 `feeRecipient`；合约不留余额；转账失败整笔回滚；两函数均有 `nonReentrant` |
| 配置 | `setNativeFeeTiers`：仅时间锁（A 类，暂停时不可）；一次设档位与收款地址 |
| 总开关 | `disableNativeFee()`：管理钱包立即把四档清零，并发事件 |
| 上下限 | 代码写死：**最低档不得低于 0.001 BNB**（WANTOS 方向 1.2 WANT，等价）；BSC 每档 ≤ 0.2 BNB，WANTOS 每档 ≤ 250 WANT。档位费用必须随金额不降。最小存入额不变 |
| 存储 | 新命名空间 `wantos.bridge.v2.NativeFee`（slot `0x996f…3a00`），未配置时全 0 即不收费；布局快照 `contracts/test/layout/NativeFee.namespace.json` |
| 事件 | 新增 `NativeFeeCollected`、`NativeFeeConfigUpdated`；`Deposited`/`BridgeOut` 不变，watcher 无需改 |

### 建议档位（BNB 按 600 美元、WANT 按 0.5 美元估算，上线前以真实价格为准）

| 存入金额（USDT） | BSC 收 | WANTOS 收 | 约合美元 |
|---|---|---|---|
| < 200 | 0.002 BNB | 2.5 WANT | 1.2 |
| 200 – 1000 | 0.01 BNB | 12 WANT | 6 |
| 1000 – 5000 | 0.04 BNB | 50 WANT | 24 |
| ≥ 5000 | 0.1 BNB | 120 WANT | 60 |

拆单不省钱：档内费用随金额增长较慢，拆成多笔每笔都要交费，总费用只会更高。

## 5. 部署方式

`REDEPLOY-PLAN-20261103.md` 正在重新部署新桥，**本改动应并入该重新部署（无需 UUPS 升级）**。并入后字节码与 codehash 会变，该文档 §4 的哈希与预测地址、`packages/offline-check/vectors.json` 都要重算。若桥已上线、要对线上实例升级，则走 48h 时间锁的 UUPS 升级，并需重新审计。

## 7. 刻意不做的

| 不做 | 少了什么 | 缓解 | 何时再做 |
|---|---|---|---|
| 价格预言机 / 自动调价 | BNB、WANT 价格大变时档位偏离 | 档位是时间锁参数，人工调整；watcher 可对比实际收入 | 每周需调多次时 |
| 严格 1% 按比例 | 档内不严格成比例 | 阶梯近似，且拆单不省钱 | 需要严格比例时（需价格） |
| 失败/退款订单退手续费 | 被拒订单的手续费不退 | 界面写明；此类订单极少 | 出现投诉时 |
| 手续费自动换成 gas 币 | 币种需人工平衡 | 手续费进离线钱包，油箱由负责人按需补 | 一个方向长期失衡时 |
| 返回整张档位表的链上接口 | 只能经 `quoteNativeFee`/`feeRecipient` 核对 | 多占 367 B，余量不够 | 余量变大或拆分合约后 |
